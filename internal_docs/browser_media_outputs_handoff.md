# Notebook output/view/canvas implementation handoff

**Source topic:** `codex/browser-media-outputs`, based on reviewed foundation `c876fd4c77517c08b60670a0ecc66029872b02b3`. This topic adds the ten Group 3 browser operations; it depends on the shared recorder interface from `0797c45d5f5d5fc932940c1a60bfa3308574690f` and, for final public recording/cleanup, the full capture family. This is implementation-specific source behavior, not PyPI 0.1.15 behavior.

`nbinlineai/browser_output_tools.py` contains nonblocking Python wrappers, registered through `nbinlineai.tools`. `frontend_bridge.normalize_action` bounds model calls. `src/browserNotebookOutputs.ts` owns a per-`BrowserOperationContext` ledger keyed by actual `IOutputModel` objects rather than indices. Its listeners on `changed`, `streamText.changed`, `outputs.changed`, and notebook cell-list changes invalidate refs and dependent canvas sources. No output renderer is created by listing or exporting. `read_output` and view/selection replies are bounded after JSON encoding; export uploads verified native bytes through the foundation's authenticated binary route. SVG is uploaded from the original MIME data, not serialized from sanitized DOM.

`src/browserNotebookViews.ts` reads the origin panel only. `src/browserNotebookCanvas.ts` accepts one stock, materialized `text/html` output renderer and scopes its DOM lookup to that output widget. A ref binds the output, widget, and actual canvas node; output changes, renderer replacement, DOM removal, and owner disposal invalidate it. `captureStream` yields one video-only track registered in the common source registry. Its `onEnded` calls `recordingSourceEnded`; there is no second recorder. `src/browserNotebookRegion.ts` composes fully visible stock PNG/JPEG/SVG outputs and single-canvas HTML output by displayed rectangles, rejecting an entire request if any requested output is unsupported. It does not capture notebook inputs or use display sharing.

Browser tests must run after a frontend build and relink on an isolated 8897 JupyterLab. Do not use 8888. Use disposable output notebooks and deterministic pixels; verify unsaved/offscreen model discovery, same-bytes replacement invalidation, no-dirty reads, focus isolation, native SVG bytes, canvas node removal/source end, region exclusions, and later Python image receipts. Final accepted review, test evidence, PR and CI status must be recorded here after those gates; do not infer them from this initial handoff.
