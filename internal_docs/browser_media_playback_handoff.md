Approved prework is main `61fa3fe517999d8f88ff328a99fc86a34dfb470b`, selected prompt `e3fcf33b20ec10cd511129cd1672b98d307e4a5c`. The selected PR base is main; foundation PR 29 is prerequisite. Do not describe this branch as shipped until reviewed and merged.

The nine public APIs live in `nbinlineai/browser_playback_tools.py` and `src/browserMediaPlayback.ts`. They use the foundation operation/receipt/owner/storage transport, exact notebook context, and its authenticated media upload and reference fetch. No second media store or global clipboard read exists. The decoder in `src/browserMediaDecoder.ts` is shared with the transformation family: `loadPlaybackMedia`, `decodeRasterMedia`, `frameAt`, and `reserveMediaWorkingPixels` provide cancellation-aware leases and enforce encoded, dimension, duration, preview, context, and tab bounds. `fetchReference` accepts an optional abort signal for HTTP cancellation. Transform clients must release returned media/frame/working-surface leases in `finally` blocks.

The public notebook is `examples/browser-media-playback.ipynb`. Each tool has an exact-name heading and `playback-<verb>-call`/`playback-<verb>-inspect` cells; setup generates a disposable PNG and WAV, and cleanup removes only those generated files. Browser-only cells are tagged `nbinlineai-ui-only` for headless execution classification. The exact notebook completed all nine tool calls in real isolated JupyterLab/kernel browser runs on Chromium and WebKit, including actual WAV decode/playback, explicit clipboard controls, and later-cell receipt inspection. Firefox completed notebook import, copy, paste, and cleanup; its audio-control cells were intentionally not executed because the pinned headless Firefox build did not progress the valid generated WAV past `loadedmetadata` (`readyState=1`), and the decoder correctly required playable data. Firefox and WebKit each passed separate real browser cases for PNG memory import/preview/close and chooser cancellation/oversize. This is a pinned headless-browser gap, not evidence about branded Firefox or real devices.

Focused checks at this playback checkpoint: 45 Python tests passed across playback wrappers, exact headless notebook setup/cleanup, bridge validation and MIME/HTTP regression; TypeScript no-emit passed; five decoder unit tests passed (including hash fallback, pixel budgets, cancelled decode and video `frameAt` lease); Ruff passed. No paid provider, personal media, real hardware, mobile browser or branded Edge/Safari was exercised. Browser tests used the disposable isolated server on port 8897 and stopped it after each run. The backend MIME repair `bc4df96b2dbd48341219256f7ffca6d6f93b0759` is included because Jupyter's default handler finish had overwritten the exact PNG/WAV `Content-Type` with JSON, preventing verified playback.
